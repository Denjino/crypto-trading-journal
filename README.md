# Crypto Trading Journal

A professional trading journal for Hyperliquid perpetual futures with real-time P&L tracking, risk management, and tilt detection.

## Features

- 📊 **Dashboard** - Account overview, open positions, recent trades
- 📝 **Trade Entry** - 2-step form with symbol search, leverage selection
- 💰 **Live Calculator** - Real-time risk/reward calculations with editable risk input
- 📈 **Active Trades** - Live P&L tracking, close at market or custom price
- 📜 **Trade History** - Closed trades with detailed view including screenshots
- ⚙️ **Settings** - Account balance, risk thresholds, tilt alerts
- ⚠️ **Tilt Detection** - Automatic warnings for revenge trading, overtrading, etc.

## Tech Stack

- React 18
- Tailwind CSS
- Vite
- Hyperliquid API (with static fallback)
